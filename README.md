# Las-estrellas-
es un videojuego educativo y de aventuras estructurado mediante Programación Orientada a Objetos (POO). El flujo inicia con un control de privacidad y la vinculación a una cuenta de padres para monitorear avances. El jugador controla a un héroe que puede personalizar su avatar y equipar herramientas para derrotar enemigos o esquivarlos

# Fase 1. analisís
Requerimientos Funcionales:
RF-01: Control de Primer Ingreso: El sistema debe detectar si el usuario inicia por primera vez para desplegar los términos de privacidad.RF-02: Vinculación Familiar: El juego debe permitir conectar una "Cuenta de Padres" para la supervisión y guardado de progresos en tiempo real.RF-03: Personalización de Avatar: El usuario debe poder modificar el aspecto visual (ropa) y equipamiento del personaje principal antes y durante la partida.

Requerimientos No Funcionales:
RNF-01: Arquitectura de Código (POO): El código fuente debe estructurarse obligatoriamente bajo Programación Orientada a Objetos utilizando herencia (super().__init__()) entre la clase base Personaje y la subclase Heroe.RNF-02: Disponibilidad y Guardado: La actualización del avance hacia la cuenta de los padres debe ejecutarse en segundo plano con una latencia menor a 2 segundos.RNF-03: Usabilidad: La interfaz del menú principal debe ser intuitiva y de fácil lectura para usuarios de cualquier edad escolar

"Las Estrellas" es un videojuego de aventura espacial diseñado por Nazaret Nicol Jiménez Porón para la clase de Programación (5° Perito Contador "A", Clave 16). El proyecto inicia con la configuración de permisos de privacidad y la vinculación de cuentas parentales. A través de un menú principal interactivo controlado por un bucle while, el jugador puede personalizar su avatar, equiparse con herramientas, ver su estado actual y comenzar la partida. Durante los niveles, el usuario se enfrenta a enemigos donde decide si usa su herramienta para derrotarlos fácilmente o si los esquiva perdiendo vidas, gestionando un sistema de Game Over, recompensas especiales al llegar a la meta, progresión entre mundos y un enfrentamiento final para rescatar a la princesa, culminando en los créditos del juego.
